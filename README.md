# 万象矿工/Omni Miner
1. 时间限制：一开始30秒。商店中可升级开采时间：每次加5秒。（价格你自己看着办）游戏画面中显示为右下角一个圆里的扇形倒计时，中间显示剩余秒数的数字。如果所有矿抓完，游戏提前结束。
2. 地形选择界面的基底矿和矿物种类一律不显示
3. 商店中的升级：增加同时发射钩爪数量1个，最多3个。穿透爪：可以捞起一条直线上所有的矿物。反射爪：触底之后弹射一次。（这三个效果可以叠加，但是要1号爪，2号爪和3号爪要各自升级。普通爪是黑色线，穿透是蓝色线，反射是绿色线。叠加的话颜色就混在一起，像虚线一样一节一节的）探测仪升级：初始每次探矿是10个，每次升级1个，最多可到20个。
保留：强化绞盘，幸运探测仪。防毒面罩改成防护服，如果没有防护服抓到辰砂、铀矿、石棉，会中断采矿游戏，显示“接触有毒矿物，你已晕倒。请去商店购买防护用品。”防护服有损耗，一件可以抓10个有毒矿。抓完10个之后销毁。这个可以多买几件堆叠。

6. 你可以加个测试模式的开关，方便我调试，测试模式就是所有地形全开，金钱9999。
